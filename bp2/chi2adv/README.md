# 고급 범주형 데이터 분석 (Advanced Categorical Data Analysis)

본 디렉토리(`bp2/chi2adv`)는 R을 활용한 **카이스퀘어 검정(Chi-Square Test) 및 고급 범주형 데이터 분석** 실습 자료와 데이터셋을 포함하고 있습니다.

## 📂 파일 구성
- `lect-2026-05-06.md`: 카이스퀘어 검정의 기초부터 고급 기법까지 다루는 핵심 강의 실습 노트입니다. (Colab Gemini 2.5 프롬프트 예제 포함)
- `data/`: 실습에 사용되는 원본 데이터셋 디렉토리입니다.

## 📊 사용 데이터셋 (Datasets)
1. **Titanic (`titanic.csv`)**: 타이타닉호 탑승객의 생존 여부 데이터. 성별과 생존 간의 연관성 및 잔차 분석 실습에 사용됩니다.
2. **Adult Census Income (`adult.csv`)**: 인구주택총조사 기반 소득 데이터. 대용량 데이터에서의 p-value 한계 극복(Cramer's V), 연속형 변수의 범주화(Quantile Binning), 교란변수 통제(CMH 검정) 등 다각적인 고급 분석에 사용됩니다.
3. **Mushroom (`mushrooms_raw.csv`)**: 독버섯 특징 데이터. 희소 범주 병합 및 Fisher's Exact Test(피셔의 정확 검정) 실습에 사용됩니다.

## 🚀 다루는 주요 통계 기법 5선
강의 노트에서는 단순 독립성 검정을 넘어 실제 학술 연구와 빅데이터 실무에서 필수적인 5가지 고급 쟁점을 다룹니다.

1. **표준화 잔차 분석 (Standardized Residuals & Mosaic Plot)**
   - 카이스퀘어 검정 후, 어떤 범주가 통계적 유의성을 견인했는지 잔차의 절대값 크기와 부호(+/-)를 통해 시각적으로 해부합니다.
2. **효과 크기 측정 (Cramer's V)**
   - 대용량 데이터(N > 30,000)에서 무조건적으로 p-value가 낮게 나오는 한계를 극복하고, 두 변수 간의 '실질적 연관성의 강도'를 0~1 사이의 객관적 척도로 측정합니다.
3. **희소 범주 처리와 Fisher's Exact Test**
   - 기대빈도가 5 미만인 셀이 많아 카이스퀘어 근사가 불가능한 경우, 몬테카를로 시뮬레이션 기법이 적용된 피셔의 정확 검정으로 엄밀한 p-value를 도출합니다.
4. **연속형 변수의 분위수 범주화 (Quantile Binning)**
   - 나이 등 연속형 변수를 단순히 선형 상관분석에 넣지 않고, 분위수로 쪼개어 생애주기에 따른 소득의 '비선형적(Non-linear) 변화 패턴'을 증명합니다.
5. **제3의 교란변수 통제 (Cochran-Mantel-Haenszel Test)**
   - '심슨의 역설(Simpson's Paradox)'을 방어하기 위해 제3의 변수(학력 등)를 층화(Stratification)하여, 억울한 통계적 착시를 걷어내고 순수한 인과 관계를 추론합니다.
